# CodeCanvas

**Fast Material 3 code editor for Android** — smooth typing, real files, offline.

[![Build](https://github.com/wized2/CodeCanvas/actions/workflows/build.yml/badge.svg)](https://github.com/wized2/CodeCanvas/actions/workflows/build.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Site:** https://wized2.github.io/CodeCanvas/ · **Releases:** https://github.com/wized2/CodeCanvas/releases

## What’s different in 3.0

Highlighting used to run on **every keystroke** for the whole document.  
3.0 **pauses highlight while you type**, then re-applies after a short delay — and skips the dual-layer paint during typing.

## Features

- Syntax colors for common languages (budget-capped for speed)
- Line numbers · word wrap · font size · Material 3 themes
- Undo / Redo · Search · Open / Save / Save As (SAF)
- Open from other apps
- Offline · no ads · no accounts
