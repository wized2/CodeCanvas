# CodeCanvas 3.1.0

## UI redesign
- Structured overflow menu: File / Edit / Settings sections
- Cleaner top bar: filename, language subtitle, modified dot, Save + Find
- Find & replace strip with match-case chip
- Recent files as horizontal chips on empty editor
- VS Code–style status bar: line count, language, UTF-8, modified
- Material 3 surfaces and tighter mobile spacing

## Unchanged
- Debounced syntax highlighting and editor performance path
- SAF open/save, themes, settings
